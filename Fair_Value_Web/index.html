Currency Fair Value (PPP)

“Currency 1 / Currency 2” reads like a ratio — e.g. choosing ZAR then EUR gives Rand per Euro. Pick any two different currencies to compare.

Fair value is estimated using every day from the start date to today as a possible PPP anchor, then smoothed into a single trend (see “How this works” below). An earlier start date feeds more history into that trend.

A complementary, trend-free view: the inflation-adjusted rate compared to its own historical range for this window, rather than to a fitted trend. See “How this works” below.

How this works

“Fair value” here means the exchange rate implied by relative purchasing-power parity (PPP): if Currency 1’s country sees hotter inflation than Currency 2’s, Currency 1 needs to weaken by roughly that differential to keep buying power even.

Dashed lines are smoothed trends, not the raw data — they’re what make the estimate robust to the choice of start date. The lower chart shows how far the raw estimate strays from that trend at each point in time, which is a rough over/under-valuation signal.

The shaded band around the fair-value trend shows the 10th-90th percentile spread of what you’d have gotten anchoring on different historical dates — a rough, honest sense of how much this estimate depends on which date you’d trust, not a precise number.

Real-rate band: switching this on adds a different, complementary view: the actual rate with the accumulated inflation differential stripped back out (so it would be flat if PPP held exactly), compared to the 10th-90th percentile range it’s occupied over the selected window. It makes no assumption about a trend — just whether today looks unusual next to this currency pair’s own recent history.

Data: every currency is tracked against the US Dollar; a cross rate between any two of them (like EUR/GBP) is built by dividing one by the other. Data is refreshed on a schedule (see data/data.json’s generatedAt) rather than live — the “latest close” marker on the charts is the most recent day in that snapshot, not an intraday quote.

This is one model among several plausible ones — see PROPOSAL.md in the project this was ported from for a fuller discussion of its assumptions and limitations.
